# G02 — Quản trị cập nhật hồ sơ giáo viên

- Ngày: **07/11/2026**. Trạng thái: **Hoàn thành**.
- Thực hiện cùng G03 theo yêu cầu người dùng; giữ rõ phạm vi hồ sơ (G02) và vòng đời/bàn giao (G03).
- Phụ thuộc: G01-v1, BR-01/02, Teacher/AuthService/AccountSecurityService và trang giáo viên đang dùng AccountManagement.

## Thay đổi

- `TeacherProfileService` và `TeacherProfileController` bổ sung quản trị detail/update/history theo **teacher profileId**, không dùng accountId thay thế.
- Teacher có `@Version`; update cần version đã đọc. Thêm `teacher_profile_events` lưu before/after snapshot, tác giả, thời gian, action, version và lý do khi đổi trạng thái. Không lưu credential/token.
- Request hồ sơ chỉ có fullName/email/phone/specialization/qualification/experience/certificate/hireDate/version; không thay role, account status, workStatus hoặc branchIds.
- Admin giao ít nhất một chi nhánh được xem profile; chỉ sửa/xem lịch sử khi quản lý toàn bộ phân công đang hoạt động. Giáo viên chưa phân công chỉ SA sửa. Staff/Teacher không gọi API quản trị.
- `/me/profile` của Teacher tham gia version/audit khi sửa email/phone. Manager đang mở version cũ nhận 409; thay tên không viết lại snapshot lớp/buổi/điểm cũ.
- Tìm kiếm account theo username hoặc họ tên Teacher, không phân biệt hoa thường và escape wildcard. Luồng chọn giáo viên khả dụng cũ giữ riêng; hồ sơ inactive vẫn xem được qua API quản trị.
- FE: `TeacherProfilePanel`, `TeacherProfileForm`, types/service mới; nút Xem của teacher mở panel có sửa/lịch sử/quyền chỉ đọc. Form có validation, busy guard, xác nhận bỏ thay đổi. Form được đặt tên riêng tránh trùng ID với modal tạo tài khoản còn trong DOM.

## API và migration

| Method | Path sau `/api/v1` | Quyền |
|---|---|---|
| GET | `/auth/teacher-profiles/{profileId}` | SA/A; A phải có giao phạm vi |
| PUT | `/auth/teacher-profiles/{profileId}` | SA/A quản lý toàn bộ phạm vi |
| GET | `/auth/teacher-profiles/{profileId}/history` | Như quyền sửa |

`V007__teacher_profile_lifecycle.sql` dùng chung G02/G03: thêm Teacher.version mặc định 0 và bảng audit, không đổi workStatus cũ hoặc tài khoản. **Chỉ đã áp dụng trên database restore riêng**, chưa áp dụng database nguồn.
